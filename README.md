## 2. 项目如何演变

研究不是围绕一个算法连续加模块，而是经历多次由对照和真实链路触发的转向：

| 阶段 | 主要问题 | 为什么继续或转向 |
|---|---|---|
| 早期 SAW | 自适应嵌入、恢复与信号质量，大规模 trial 验证 | 后续修正判决、舍入和评估实现后，旧大表不能继续当作当前冻结方法或真实 SOTA 复现 |
| 轻量 Haar/QIM | 去除高成本分解，推导扰动，建立质量门控、存储保护和任务验证 | 形成可复用工程与解析工具；加强无水印认证对照后，“必须嵌水印”的必要性没有成立 |
| 接收方指纹 | 发行不同副本，在外部标签消失后归因；探索共同相位、码本、串谋和源登记 | 将任务从完整性认证变为接收方证据；强归档匹配和源检索基线逐步收窄算法独占优势 |
| 未知处理与实际文件 | 延迟、增益、未知滤波、连续 EDF、二次整数存储和跨域 | 家族估计正确仍可归属失败，量化、上下文和读出接口成为核心；换更高位深只能解释部分尾部问题 |
| 差分与平滑 | 希望消去共同响应，同时降低结构扰动 | 同步、拒判、多窗、空间混合和下游验证逐步完善；平滑对直接差分的任务优势受编码网格影响 |
| P188–P190 | 普通／投影／候选响应估计、校准敏感性、独立人员确认 | 候选程序有覆盖收益和拒判代价；五校准程序主要点等价，选择器增量负结果保留 |
| P191 | 同响应身份缺陷、能量归一化、FIR 容量、现代载体和新确认 | DEV 有改进，但更晚新源近码反例表明：只减少未知响应误差，尚不足以保证跨源拒判 |

这些概括的具体数字、分母、阶段边界、原始文件和转向原因，均在详细历史中展开。

## 3. 最影响下一步判断的事实

### 3.1 早期资产可以重新利用，但需要带上当时的强对照

轻量化、解析失真、范围保护、局部质量门控和真实序列化并未失去价值。早期认证路线受到的挑战是：在具体威胁模型中，原刻度无水印 HMAC 等对照已能完成相应任务，不能仅凭恢复率证明必须嵌入。

因此可以研究新的适用问题，但要回答“信号内标记提供了什么外部登记、密码认证或归档匹配无法替代的能力”。新选题不应只换水印变换名称。

### 3.2 强基线多次改变了研究结论

后续历史里出现了实际发行中心、强相关／归档匹配、处理后模板、处理族拟合等基线。某些早期优势在同信息、同状态或同预算后被追平。这些是设计新题的依据，不是所有旧方法都无效的证明。

一个具体例子是 P161：clean＋压缩差分的可重建存储成本曾仅为原方案的 6.75%，因此不能把“保存发行副本天然昂贵”当作未经比较的优势。

### 3.3 P190 的结果与贡献边界

P190 共同主要规则：登记 192/192，`.025` 接受 0/384，`.0125` 接受 30/192，其中全部 30 次集中于 elliptic 的 30/64。独立目标是八人，错源四人。

五程序在确认前已等价，原选择器增量标准失败；该负结果与共同规则有限网格迁移并存。它不能靠增加相同规则下的确认人数变成正增量。

### 3.4 P191 有开发进展，也有新的关键反例

DEV 中 257/exact 在 fit/select 各 96/96、近码与控制零接受；压力感知 129/compatibility 则为 95/96、94/96。后续新人员确认已开始。

较晚的六名完整 smooth 部分观察中，257/exact 登记 144/144，但 `.0125` 接受 43/144，其中 elliptic 13/48；129/compatibility 登记 142/144、压力 0/144，257/compatibility 登记 128/144、压力 0/144。这是**部分已保存结果**，不是八人最终统计；冻结的绝对零误接收要求已经遇到反例。

OpenBMI018 的后确认真实算子诊断更有区分力：原 6/24 压力误接收全部持续，真实算子分支为 8/24，登记仍 24/24。它说明新失败需要考察当前字典投影距离及全局阈值迁移，不能继续全部解释为未知滤波估计不足。这是单源、事后、特权算子诊断，不是新的部署方法结果。

具体观察时间、文件和计数在 `docs/LATEST_HISTORY_STATUS.md` 及近期历史章节。项目仍运行，交接包不追踪后续实时进度。

## 4. 这次允许讨论哪些升级／转题

允许 Opus 挑战现有问题设定，提出：

- 保留当前主线，但把“源相关可分性、响应误差与拒判半径”发展为真正的方法贡献；
- 将某项已证实机制或边界组织成更强的实证／基准论文；
- 重新利用轻量可分析嵌入、实际存储保护、任务结构、编码边界或资源工具，提出不同终点的新题；
- 比较信号内指纹、无水印认证、源登记和发行归档等完整系统，寻找明确的不可替代能力；
- 使用现代有限码本载体与强简单基线研究新的可靠性问题。

以上是资产支持的问题空间，不是已经确认的新颖选题。请核实最近原始工作，给出方法级差异，避免把“项目里没试过”当作“领域里没人做过”。

当前进行中的冻结实验继续保持原规则。新选题可以提出新载体、访问模型或预算，但要明确这些变化，并在新开发／冻结之前确定，不能追溯性改写旧比较。

## 5. 研究资产与约束

项目已有：

- 多数据域读入、人员/会话角色管理和真实 EDF/BDF 写读；
- 相位、直接差分、平滑差分、空间、混合、Haar/QIM 及现代载体适配；
- 归档、源检索、相关／余弦、经典检测、响应估计和开集拒判；
- 多窗融合、共同对齐、连续处理及量化审计；
- CSP/LDA、带功率、EEGNet 的任务验证与真实训练经验；
- 保存分数、码本/资产收据、冻结与修订、配对控制和复现工具。

数据来自旧 Main 工程及 BCI、ERP、EEGMMIDB、睡眠/癫痫、OpenBMI 等不同阶段。它们的独立人员数、是否已经被开发查看及任务标签质量不同；应按具体原报告确认，不能把多窗、多身份、多处理合并为独立人群。

原始 EEG、模型权重和完整环境没有放入本包。实际可用的新确认人员也不能因在旧报告中叫“新记录”而永久保留未见资格。
